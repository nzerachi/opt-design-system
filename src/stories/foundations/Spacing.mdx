# Spacing

Opticule uses a **4px base unit** spacing scale. All spacing tokens are multiples of 4px, ensuring consistent rhythm throughout the UI.

---

## Named Aliases

| Alias | Step | Value | Usage |
|---|---|---|---|
| `xs` | 2 | 8px | Tight gaps, icon padding |
| `sm` | 3 | 12px | Small gaps, compact UI |
| `md` | 4 | 16px | Default padding, gaps |
| `lg` | 6 | 24px | Section padding |
| `xl` | 8 | 32px | Large section gaps |
| `2xl` | 12 | 48px | Page-level sections |
| `3xl` | 16 | 64px | Hero sections |

---

## Usage

Use Tailwind spacing utilities (`p-4`, `gap-6`, `mt-8`) which map directly to this scale. All components in Opticule DS use tokens from this scale — no arbitrary pixel values.
