# Colors

Opticule's color system is built on three brand primaries — **Orange**, **Purple**, and **Folly** — expressed through a full perceptual scale from 50 to 950. Semantic tokens map these primitives to meaningful roles: background, foreground, border, interactive, and status.

## Semantic Tokens

These tokens are what components consume — they automatically switch between light and dark themes.

| Token | Light | Dark | Usage |
|---|---|---|---|
| `--background` | `#ffffff` | `#000000` | Page background |
| `--foreground` | `#000000` | `#ffffff` | Primary text |
| `--muted-light` | `#f0f0f0` | `#1a1a1a` | Subtle backgrounds |
| `--border` | `#e5e5e5` | `#262626` | Dividers, outlines |
| `--brand-orange` | `#ff8000` | `#ff8000` | Interactive focus, CTAs |
| `--brand-purple` | `#cc33ff` | `#cc33ff` | Success, accent |
| `--brand-folly` | `#ff004f` | `#ff004f` | Errors, destructive |

---

## Usage Guidelines

- **Never** use raw hex values in components — always use CSS custom properties (`var(--brand-orange)`) or Tailwind classes (`text-brand-orange`).
- Brand Orange (`#ff8000`) is the **primary interactive color** — focus rings, active states, CTAs.
- Brand Purple (`#cc33ff`) represents **success** and positive states (not green, per Opticule's brand).
- Brand Folly (`#ff004f`) is used exclusively for **errors and destructive actions**.
