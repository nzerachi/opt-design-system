# Shadows & Elevation

Opticule uses a 7-level shadow scale that communicates **elevation** — the perceived height of a surface above the page. Larger shadows signal higher elevation and more importance.

## Usage

Components access shadows via CSS custom properties: `shadow-[var(--shadow-sm)]`. The scale automatically adjusts between light and dark themes — dark theme shadows are slightly more diffuse to compensate for reduced ambient contrast.
