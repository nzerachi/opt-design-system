# Typography

Opticule uses **Ubuntu** as its primary typeface — a humanist sans-serif that balances technical precision with approachability. Ubuntu Mono is used for all code specimens.

---

## Font Families

| Role | Family | Weights |
|---|---|---|
| Sans (default) | Ubuntu | 300, 400, 500, 700 |
| Mono | Ubuntu Mono | 400, 700 |

Both families are self-hosted as `.woff2` files — no Google Fonts CDN dependency.

## Font Weight Scale

| Token | Value | Usage |
|---|---|---|
| `font-light` | 300 | Decorative large headings |
| `font-normal` | 400 | Body text, descriptions |
| `font-medium` | 500 | Labels, captions, UI text |
| `font-bold` | 700 | Headings, emphasis |

---

## Line Heights

| Scale | Value | Usage |
|---|---|---|
| `leading-none` | 1 | Display-size headings |
| `leading-tight` | 1.1–1.25 | H1–H4 |
| `leading-snug` | 1.375 | H5–H6 |
| `leading-normal` | 1.5 | UI text, labels |
| `leading-relaxed` | 1.6 | Body prose |
| `leading-loose` | 2 | Spacious text blocks |

---

## Usage Guidelines

- Use `Heading` component for all heading-level text (h1–h6).
- Use `Text` component for body, label, and caption variants.
- Never use raw `<h1>`–`<p>` tags inside components — go through the typography system.
- Code and monospace text always uses Ubuntu Mono via `font-mono` utility class.
